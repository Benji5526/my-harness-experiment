# my-harness-experiment

하네스 도구(Claude Code)의 불편 하나를 반증 가능한 가설로 바꿔 실험한 과제 보고서입니다.
전체 내용은 [experiment-01.md](experiment-01.md)에 있습니다.

## 가설

같은 모델·작업·프롬프트에서 권한 allow 규칙을 "편집 + `python -m unittest`"로 좁게 열어 두면(P1), 규칙 없이 매번 묻는 경우(P0)보다 (a) 승인 요청이 절반 이하로 줄고 (b) 해결률이 유지되며 (c) 승인 대기를 반영한 총 시간이 줄어든다.

## 실험 설계 요약

| 구분 | 내용 |
|---|---|
| 고정 | Claude Code 2.1.301, 모델 `claude-sonnet-5-5`, 같은 프롬프트 3개, 같은 fixture(`fixture/`), manual 권한 모드, project 설정만 로드, 시도마다 새 폴더·새 세션 |
| 조작(하나) | 권한 allow 규칙: P0 없음 / P1 편집+테스트 실행만 / P2 넓게 |
| 측정 | 해결률, 승인 횟수(모의 승인자 로그), 벽시계 시간, 토큰, 턴 수, 비용 |
| 반론·통제 | 시간은 모델이 지배 → d=0과 d=5·15·30초 분리 보고 / 승인 감소가 규칙 때문인지 → 승인 원문 분류 / 소표본 → 중앙값+범위 |
| 사전 판정식 | (a)·(b)·(c) 모두 충족 시 지지, 아니면 기각 (실행 전 고정) |

## 결과 (3 정책 × 3 작업 × 3 반복 = 27회)

| 작업 | 정책 | 해결 | 승인 횟수(중앙값) | wall_s | T(15s) |
|---|---|---|---|---|---|
| T1 | P0 | 3/3 | 3 | 13.6 | 58.6 |
| T1 | P1 | 3/3 | 0 | 12.0 | 14.4 |
| T2 | P0 | 3/3 | 3 | 14.1 | 58.1 |
| T2 | P1 | 3/3 | 0 | 14.8 | 14.8 |
| T3 | P0 | 3/3 | 2 | 12.9 | 42.9 |
| T3 | P1 | 3/3 | 0 | 12.2 | 12.2 |

**판정: 가설 지지** — 단, 승인 감소는 설계상 거의 당연한 결과이고, 벽시계 시간 자체는 규칙과 무관했습니다(줄어든 시간은 사람의 승인 대기뿐이며 그 값은 가정 d=15초입니다). 실제 사람의 대기 시간은 측정하지 않았습니다. 자세한 한계는 experiment-01.md 6절.

## 재검토 조건

- 실제 승인 대기가 거의 0초로 측정되면 (c)의 이득이 사라집니다.
- 큰 작업에서 P1 해결률이 P0보다 낮아지거나 승인이 자주 새면 결론을 철회합니다.
- Claude Code 버전·기본 권한 모드가 바뀌면 재실행합니다.
